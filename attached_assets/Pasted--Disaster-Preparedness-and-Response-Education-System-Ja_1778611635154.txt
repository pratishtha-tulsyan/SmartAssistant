# Disaster Preparedness and Response Education System (Java Web App MVP)

## 1. Project Overview

### Project Title

Disaster Preparedness and Response Education System

### Goal

A Java-based web application for schools and colleges that helps students, teachers, and administrators learn about disaster preparedness, participate in training, access emergency resources, receive alerts, and practice disaster response using quizzes and simulations.

### MVP Objective

Build a fully functional Minimum Viable Product (MVP) with:

* User authentication
* Educational modules
* Quizzes
* Emergency contacts
* Disaster reporting
* Alert system
* Admin dashboard
* Basic analytics

# 8. MySQL Database Schema

## users Table

```sql
CREATE TABLE users (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    name VARCHAR(100),
    email VARCHAR(100) UNIQUE,
    password VARCHAR(255),
    role VARCHAR(20)
);
```

## learning_modules Table

```sql
CREATE TABLE learning_modules (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    title VARCHAR(255),
    description TEXT,
    category VARCHAR(50),
    content_url VARCHAR(255)
);
```

## quizzes Table

```sql
CREATE TABLE quizzes (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    title VARCHAR(255),
    category VARCHAR(50)
);
```

## questions Table

```sql
CREATE TABLE questions (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    quiz_id BIGINT,
    question TEXT,
    option_a VARCHAR(255),
    option_b VARCHAR(255),
    option_c VARCHAR(255),
    option_d VARCHAR(255),
    correct_answer VARCHAR(10)
);
```

## incidents Table

```sql
CREATE TABLE incidents (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    user_id BIGINT,
    title VARCHAR(255),
    description TEXT,
    location VARCHAR(255),
    status VARCHAR(50),
    image_url VARCHAR(255)
);
```

# 12. Backend Code Structure

## Entity Example

### User.java

```java
@Entity
@Table(name = "users")
public class User {

    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;

    private String name;
    private String email;
    private String password;
    private String role;
}
```

---

## Repository Example

### UserRepository.java

```java
@Repository
public interface UserRepository extends JpaRepository<User, Long> {
    Optional<User> findByEmail(String email);
}
```

---

## Service Example

### UserService.java

```java
@Service
public class UserService {

    @Autowired
    private UserRepository userRepository;

    public User register(User user) {
        return userRepository.save(user);
    }
}
```

---

## Controller Example

### AuthController.java

```java
@RestController
@RequestMapping("/api/auth")
public class AuthController {

    @Autowired
    private UserService userService;

    @PostMapping("/register")
    public ResponseEntity<?> register(@RequestBody User user) {
        return ResponseEntity.ok(userService.register(user));
    }
}
```

# 13. Spring Security Configuration

```java
@Configuration
@EnableWebSecurity
public class SecurityConfig {

    @Bean
    public SecurityFilterChain securityFilterChain(HttpSecurity http) throws Exception {
        http
            .csrf().disable()
            .authorizeHttpRequests(auth -> auth
                .requestMatchers("/api/auth/**").permitAll()
                .requestMatchers("/admin/**").hasRole("ADMIN")
                .anyRequest().authenticated()
            )
            .formLogin();

        return http.build();
    }
}
```
